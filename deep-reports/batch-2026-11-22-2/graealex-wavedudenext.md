## 一句话理解

这是一个“光学实验台的模拟器”：在画布上摆光源、透镜、镜子，波的传播和叠加实时算给你看，还能放探测器画曲线、导出动画——相当于把物理课的光学实验搬进电脑。

## 通俗解释

波动光学（干涉、衍射、折射）抽象难懂，因为看不见。WaveDude Next 把它变成可视化：你在画布上放点光源或发射器阵列，加透镜、镜子等光学元件（甚至把任意图片变成折射率场景），程序实时计算并同时显示两幅图——“波场”（波的正负摆动）和“强度”（能量随时间的平均）。可以放探针记录某点或某条线的波形/强度并画成曲线（线性或对数轴），拖动时间轴到任意帧、循环播放片段、调亮度或自动适配（来源：README “What you see”、“Scenes”）。界面有英德法荷四种语言、深浅主题（来源：README）。它是经典 Wave Dude 2D 的续作，针对旧版做了多项改进（来源：README “Improvements over Wave Dude 2D (Classic)”）。

## 它不是什么

1. **不是 3D 光线追踪渲染器**。它是 2D 波动仿真，算的是波的传播与叠加，不是 3D 几何光学（来源：README 开头）。
2. **不是Windows 之外的跨平台软件**。README 明确“for Windows”（来源：README 开头）。
3. **不是简单的动画演示**。它支持自定义场景、探针、时间轴控制、视频导出、配色方案和颜色映射，是一套实验工具（来源：README “What you see”、“Export”）。
4. **不是只支持单色点光源**。支持点源、发射器阵列（形成光束和定向脉冲）、随机偏移形成非相干源（来源：README “Scenes”）。
5. **不是旧版 Wave Dude 2D 本身**。它是 “Next” 续作，README 专列了对经典的改进（来源：README）。

## 痛点

- **波动光学不可见**：干涉/衍射靠公式难建立直觉，实时可视化工具有教学价值。
- **旧版工具功能受限**：Classic 版在场景、导出、探针等方面不足，Next 版逐项改进（来源：README headings）。
- **实验结果难以保存/分享**：支持导出 BMP/PNG 序列或 AVI（来源：README “Export”），方便做教材或演示。
- **语言/视觉可及性**：四种界面语言与深浅主题降低使用门槛（来源：README）。

## 核心功能（依据 README，注明来源）

- **波场与强度双视图**：波的正负摆动与随时间平均的能量强度并排显示（来源：README “What you see”）。
- **探针与曲线**：点/线探针记录波场或强度，图上叠加曲线，线性或对数轴（来源：README）。
- **时间轴控制**：拖到任意帧、任意速度播放、循环某段、手动或自动亮度、内置与自定义配色（来源：README）。
- **丰富光源与元件**：点源、发射器阵列、光束/定向脉冲、随机偏移非相干源；球面透镜与镜子、折射/吸收材料、任意图片转光学元件（来源：README “Scenes”）。
- **视频导出**：BMP/PNG 图像序列或 AVI（来源：README “Export”）。
- **界面与示例**：英德法荷四语、深浅主题、33 个示例项目（最近提交信息提到 “The solution lists the 33 examples”）（来源：README 与 commit message）。

## 使用场景

- 物理教学：演示杨氏双缝、衍射、干涉、透镜聚焦等现象。
- 光学工程：快速验证波场分布的定性行为。
- 制作科普动画：导出帧序列或 AVI 做视频素材。
- 把照片/图片变成折射场景做创意可视化。

## 适用人群

物理教师/学生、光学爱好者、做科普可视化的人。Windows 用户专属。

## 总结

WaveDude Next 把“看不见的波动光学”变成可交互、可导出、多语言的实验工具，是经典 Wave Dude 2D 的现代化续作。它定位清晰——教学与定性可视化，而非精确光学设计。298 star、0.1.x 版本说明它还小众且早期，但对物理教育和科普创作，这类工具的价值超出其代码规模。
