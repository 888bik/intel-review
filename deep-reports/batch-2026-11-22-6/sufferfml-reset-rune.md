## 一句话理解
一个 macOS 菜单栏小工具，把剩余的 Codex 重置额度当成会过期的符文收进瓶子，在到期前自动帮你用掉。

## 通俗解释
README 不长但信息清楚：每次 Codex 重置额度就像一枚会过期的符文，这个常驻菜单栏的 App 复用你本机的 Codex 登录，在到期前（默认提前 10 分钟，可选 5/30/60 分钟）尝试自动兑换，避免白白浪费。名字来自 Dota 2 里能存再生符文的瓶子。需要 macOS 13 以上和已登录的 Codex CLI 0.153.0 以上版本；自动使用默认关闭，可随时停下。

## 它不是什么
1. 不是增加额度或绕过限制的工具，README 明说是否可兑换由 Codex 决定
2. 不是跨平台工具，Windows 支持仍在计划中、尚未发布
3. 不是需要管理一堆文件的复杂应用，只盯住一个用途
4. 不是会强制唤醒 Mac 的守护进程，睡眠或关机跨过过期点可能错过重置

## 痛点
- Codex 的备用重置次数会过期，闲置就是浪费
- 手动盯着倒计时去重置很烦
- 不想把额度信息交给第三方托管

## 核心功能（依据 README，注明来源）
- 菜单栏瓶子显示剩余符文数与下次过期时间，点开可看库存详情（来源：README Features）
- 轻量调度：已知最早过期时间直接定时，库存为空或信息不全时周期性检查（来源：README Features）
- 配额与战斗日志：展开面板可看额度、尝试时间与活动记录（来源：README Features）
- 命令行控制：status、refresh、pause、config lead 等（来源：README Command line）
- 提供 Apple Silicon 与 Intel 的 DMG，以及 npm 全局安装两种方式（来源：README Install）
