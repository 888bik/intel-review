## 一句话理解
üxzView 是一个图片查看器，Windows 10 与 11、Linux、macOS 都计划支持，用 C++20 和 Qt 6 写成，灵感来自 IrfanView 和 nomacs；目前处于开发中，预制包只覆盖 Windows x64。

## 它不是什么
1. 不是成熟稳定的 IrfanView 替代品——README 明说仍在开发中，Linux 和 macOS 原生构建尚未验证。
2. 不是专业图像编辑器——有裁剪、调色、文字、批处理，但不是 Photoshop 或 GIMP 那类分层编辑器。
3. 不是纯查看器——它带 OCR、条码、批处理、水印等编辑或识别功能，也有扩展系统。
4. 不是只有 Windows——源码与构建流程面向三个平台，但只有 Windows 有预制包。
5. 不是单文件绿色软件——便携模式需要把 portable.mode、IxView-data、tools 一起带着走。

## 痛点
- 经典看图软件用户想要一个现代、开源、跨平台的替代。

## 核心功能（依据 README，注明来源）
- 浏览与查看：快速文件夹浏览、键盘导航、图片缓存，全屏查看、鼠标导航、幻灯播放、区域放大，任意角落显示分辨率、DPI、文件大小与所选元数据，居中缩略图条含前后 1 到 5 张（来源：README Features）。
- 编辑与批处理：缩放、自由裁剪或按预设与自定义比例裁剪、旋转、翻转、调色与自动校正，带实时预览的文字叠加与单像素取色，可复用配置的可视化批处理、水印与转换报告（来源：README Features）。
- 管理与整理：评分、色标、元数据搜索、重复检测、系统回收站和图片编辑的撤销与重做（来源：README Features）。
- 格式支持：JPEG、PNG、WebP、TIFF、GIF、APNG、PSD 合成图、SVG、RAW 及插件格式；多页 PDF 阅读与图像导出；内置 jpegli 导出、可配置默认保存格式；支持动画、16 位、ICC、EXIF、IPTC、XMP，ZIP 与 CBZ 通过可选归档插件（来源：README Features）。
- 识别工具：Windows 包内置 ZXing-C++ 的 QR 与条码读取与 Tesseract 的 OCR（英德法日韩），工具放在程序旁的 tools 目录，仅在调用时运行，可移除或改路径，不改动图像像素（来源：README Recognition tools）。
- 扩展与便携：图片格式与功能两类扩展、可配置存储目录；便携模式在 Options 设置中开启，首次启用复制数据，需与程序一起移动（来源：README Features / Portable mode）。
- 平台与构建：Windows 用 bootstrap 脚本固定依赖；Linux 与 macOS 按平台指南安装 Qt 6.8 以上、CMake 3.24 以上、libjpeg-turbo 等后构建，CMake 自动抓取并校验 jpegli 与 Highway 源码（来源：README Build from source）。

## 使用场景
- Windows 上找 IrfanView 或 nomacs 式看图软件，并希望带编辑和识别工具。
- 需要按文件夹快速翻图、全屏演示、看 EXIF 与分辨率等信息。
- 批量给一组图片改尺寸、加水印、转格式并保存可复用配置。
- 离线识别截图里的二维码与条码，或从图片里提取文字。
- 想用便携模式把设置、评分和扩展装进 U 盘随身带。

## 适用人群
Windows 图片重度用户、摄影爱好者、需要离线 QR 与 OCR 的办公场景；也想看 Qt 6 桌面应用如何做插件与跨平台构建的 C++ 开发者。不适合要求 Linux 与 macOS 开箱即用、或需要专业分层编辑的人。
