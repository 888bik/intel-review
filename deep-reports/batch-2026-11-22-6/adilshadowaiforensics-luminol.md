## 一句话理解
一个免安装的 Windows 检查工具：告诉你这个账户里有哪些 AI 工具的使用痕迹、这些痕迹最后改动于何时，以及大概什么时候会消失。

## 通俗解释
README 篇幅主要花在“限制”上：只查当前 Windows 账户、只查已知位置、不读超过 260 字符的完整路径、不保留也不报告对话正文、缺失结果不能证明没用过 AI。它检查 19 类证据，每类都有正反合成测试；默认离线不联网，可选的 OpenTimestamps 封印才会发出一个 32 字节指纹。0 star，刚入库，尚无社区验证。单次检查耗时 10 到 34 秒是作者在一台机器上的自述、未独立核实。

## 它不是什么
1. 不是键盘记录或内容审查工具，只报告记录是否存在和文件最后改动时间。
2. 不是法律证据，README 明说不保证法院或监管机构接受。
3. 不证明某个人说过什么，也不覆盖云端、其他设备或已删除的内容。
4. 不读取 ChatGPT 桌面端 .codex 下的 history.jsonl 与 sqlite/codex-dev.db，0.1.1 尚未覆盖，计划 0.1.2 加入。
5. 不是官方签名软件，未做代码签名，SmartScreen 可能拦截。

## 痛点
- 取证套件告诉你“有什么”，但不告诉你“还能留多久”。
- AI 应用缓存会自动清理，证据窗口很短。
- 直接运行来源不明的 PowerShell 脚本本身就有风险，因此项目公开了源码、哈希与构建方式。
- 报告含个人信息，若 Documents 被 OneDrive 同步会顺带上传到云端。

## 核心功能（依据 README，注明来源）
- 检查 19 类 AI 使用痕迹，每类都有正向与反向合成测试覆盖（来源：README LUMINOL by Shadow AI Forensics）
- 读取文件名、大小与日期，查浏览器历史中的 AI 站点名、Windows 通知数据库，以及下载文件的 Mark of the Web 站点（来源：README Run it）
- 输出 HTML 与 JSON 报告到 Documents/LUMINOL，含来源标注的时钟、部分或未读检查项、建议下一步和保全声明草案（来源：README Run it）
- 默认不联网、不安装、无需管理员权限；可选封印向 OpenTimestamps 发送 32 字节指纹（来源：README Run it）
- 公开 Luminol-Check.ps1、catalog.json 与合成测试，发布双次构建字节一致的 zip 并给出 SHA-256（来源：README Check the download and the code）

## 使用场景
- 企业 IT 在授权设备上盘点 AI 工具痕迹并评估留存窗口
- 个人在自己的电脑上确认某些 AI 应用是否留下了记录
- 需要一份不改变文件内容的现场检查记录
- 想验证某类痕迹在关闭浏览器后是否会被自动清理

## 适用人群
有明确授权的 IT、合规或数字取证人员；关心自身设备隐私的个人用户。若怀疑某个具体的人，README 建议由 IT 运行而不是让本人运行。

## 注意事项
- 只允许在自己拥有或获授权检查的电脑上运行；报告属于个人信息，应按邮件级别处理。
- 报告随缓存文件数量增长而变慢，作者在一台 Windows 11 Pro 26300 机器上于 2026 年 10 月 30 与 31 日测得 10 到 34 秒，为自述、未独立核实。
- 组策略可覆盖 -ExecutionPolicy Bypass；在 Constrained Language Mode 下脚本会停止运行。未做代码签名，运行前务必核对 SHA-256。
- 关闭浏览器可能触发自动清理历史，从而删除证据；README 建议先检查该设置或让检查在浏览器打开时运行。
