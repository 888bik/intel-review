## 一句话理解
Poptato 是一个小而专注的 Linux 应用启动器：按一下快捷键弹出菜单，打字搜索，回车选中，就能启动桌面应用、运行命令、从管道里挑一行文本，或者调用你自己定义的菜单。

## 通俗解释
如果你用过 Rofi、dmenu 或 fzf，Poptato 的定位不难理解——它是同一类键盘优先的选择器，只是用 Rust 和 GTK4 重写，并做了一个土豆主题的轻松品牌。README 不长但组织得很好，把四种模式、键位、配置示例、主题和自定义模式都讲清楚了：apps 模式找已安装桌面应用，run 模式在 PATH 里找可执行文件或直接敲命令，dmenu 模式从标准输入读行并把选中项打印到标准输出，custom 模式则用一个命令生成菜单、选中后还能触发动作。搜索默认模糊匹配，也可切子串或前缀。在支持 layer-shell 的 Wayland 合成器上它作为键盘聚焦的浮层出现，在 X11 上则用无边框 GTK 窗口。项目刚创建三天，10 星、0 fork，发布到 v0.1.1，属于典型的能用了但还没经过社区打磨的阶段。

## 它不是什么
1. 它不是桌面环境或面板：只负责弹菜单和选择，不管窗口管理和系统托盘。
2. 它不是完整的命令 shell：README 明说直接运行命令，管道、&&、重定向需显式调用 shell。
3. 它不是 macOS 或 Windows 工具：只面向 Linux，并依赖 GTK4。
4. 它不是配置零负担的成品：主题、按键、自定义模式都要写 config.toml，虽然提供了 --print-config 起点。
5. 它不是成熟替代品：10 星、0 fork、v0.1.1，尚无广泛用户验证。

## 痛点
- 桌面环境自带启动器不够快或不够可定制，用户想要 fzf 式键盘流。
- Rofi 等老工具的配置语法和观感不合口味，想要一个 GTK4 原生实现。
- 需要把一段管道输出快速变成可交互选择并拿回结果，例如挑窗口、挑颜色。
- Wayland 下弹窗焦点行为因合成器而异，需要 layer-shell 与无边框窗口两种回退。
- 想让选择器直接触发动作而不只是打印结果，需要可扩展的自定义模式。

## 核心功能（依据 README，注明来源）
- 四种模式：apps 查找并启动桌面应用，run 查找 PATH 可执行文件或输入带参命令，dmenu 从标准输入读行并输出选中行，custom 由命令生成菜单并执行动作（来源：README Three ways to pop）
- 匹配方式：默认模糊匹配，同时支持子串与前缀，可搜索名称、描述与关键词（来源：README Three ways to pop、Season to taste）
- 键盘操作：方向键或 Ctrl+J/K 移动、Page Up/Down 翻页、回车确认、Shift+Enter 接受输入、Esc/Ctrl+G 取消（来源：README Make the keyboard do the work）
- 类 Rofi 别名与无窗口查询：支持 -show drun、--dmenu、--list --query 等用法，便于脚本集成（来源：README Actually useful little tricks）
- 配置与主题：config.toml 管理菜单宽高、位置、匹配方式、字体与配色、按键绑定，内置多套主题并支持 CSS 样式钩子（来源：README Season to taste）
- 自定义模式：source 命令生成条目，占位符作为单一参数替换，可选 action 执行，--list 可预览（来源：README Grow your own mode）
- 安装路径：AUR 的 poptato-bin 包，或从源码用 cargo install 构建，可关闭 layer-shell 特性（来源：README Get it while it's hot）

## 使用场景
- 给窗口管理器绑定一个快捷键，作为日常应用与命令的统一入口。
- 在脚本里把任意文本列表通过管道交给 Poptato，让用户选择后拿回结果。
- 自定义颜色、剪贴板历史、SSH 主机等小型菜单，并在选中后触发动作。
- 在 Wayland 合成器上用 layer-shell 浮层，或在 X11 上用无边框窗口获得一致体验。
- 用 --check-config 校验配置，用 just build/check/test 参与开发。

## 适用人群
适合喜欢键盘驱动工作流、愿意写点 TOML 配置的 Linux 桌面用户，尤其是使用 niri 等 Wayland 合成器的人。装有 AUR 的 Arch 系用户安装最省事；从源码构建需要 Rust 1.92+、GTK4 开发文件与 pkg-config。追求开箱即用或跨平台的用户不适合。
