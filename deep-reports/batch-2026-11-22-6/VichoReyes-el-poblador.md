## 一句话理解
把经典桌游《卡坦岛》（Settlers of Catan）搬进终端：一个用 Go 写的文字界面游戏，既能本地多人在同一台机器上轮流操作，也能连到作者搭建的 SSH 服务器和别人开房对战。

## 通俗解释
README 很短（约两千多字符），信息有限，但把玩法和入口交代得清楚。它本质上是一个 TUI（终端用户界面）游戏：棋盘、资源、交易与建设都通过键盘光标在字符界面里完成，不依赖图形桌面。作者给的最省事入口是一行 SSH 命令，连上 catan.vichoreyes.cl 的 2222 端口就能看到开放房间；想自己掌控，则可以用 go install 安装、下载 Release 二进制、克隆编译，甚至打成 AUR 包。启动新局是在 new 后加两到四个玩家名，读档是 load 加存档文件。操作只有方向键、回车、Esc 等少数几个键，按 e 还能切换 emoji 显示，避免某些终端对齐错乱。

值得注意的是在线部分：服务器架在 GCP，存档会在 30 天后被删除，作者也明确表示尚未承诺旧存档的向后兼容。本地模式下还可以用数字键 1 到 4 切换视角、0 回到当前回合玩家。它更像一个把桌游规则认真实现出来的技术玩具，而不是商业游戏平台；5 star、0 fork 的规模说明目前仍是小众项目。最近的提交是修复强盗受害者选择，说明作者在持续打磨规则细节。

## 它不是什么
1. 不是图形版卡坦岛，没有鼠标点击的界面，全靠键盘在终端里操作。
2. 不是官方授权或商业发行版，只是个人用 Go 实现的开源版本。
3. 不是稳定托管的在线服务，作者自建服务器仅为方便试玩，存档 30 天即删且不保证兼容。
4. 不是移动端或网页游戏，虽然可通过 SSH 客户端间接连接，但原生体验只在终端。
5. 不是规则教学工具，README 未提供规则说明，默认读者已经了解桌游玩法。

## 痛点
- 想和朋友随时开一局卡坦岛，但凑不到实体桌游，或大家不在同一地点。
- 很多在线桌游平台要求注册、下载客户端或依赖图形界面，在纯终端环境里不方便。
- 已有的一些文字游戏实现缺少在线多人能力，或者部署起来过于复杂。
- 桌游规则状态机（资源交易、强盗、最长道路）本身容易写错，需要一个持续修 bug 的开源实现可供参考。

## 核心功能（依据 README，注明来源）
- 终端界面下完整的卡坦岛对局，支持 2 到 4 名玩家（来源：README Running the Project 中 new 命令说明）
- 本地存档与读档，用 load 命令恢复先前对局（来源：README Load a saved game）
- 在线多人：连接作者托管服务器查看开放房间，并用保存码恢复线上对局（来源：README Online Multiplayer）
- 自托管服务器：运行 serve 后在本地 2222 端口起服务，玩家用 SSH 连接（来源：README Self host）
- 键盘操作与视角切换：方向键移动、回车确认、Esc 取消、e 切换 emoji、数字键切换本地玩家视角（来源：README Controls）
- 多种安装方式：Release 二进制、go install @main、源码编译或 AUR 包（来源：README Installation）

## 使用场景
- 在服务器、无图形界面的开发机上和同事打一局文字版卡坦岛。
- 通过 SSH 临时开房，和异地朋友进行回合制对战。
- 自己搭一台小服务器，给固定圈子的朋友提供长期对战入口。
- 想读源码研究一个完整桌游状态机与 TUI 交互的实现方式。

## 适用人群
熟悉终端和 Go 的玩家、喜欢回合制桌游但常在纯命令行环境工作的人，以及想研究 TUI 游戏或 SSH 多人架构的开发者。完全没接触过卡坦岛规则、也不打算先读规则的人不建议直接上手。
