## 通俗解释
README 说，跑 Linux 的手机（postmarketOS 或 Ubuntu Touch）不需要谷歌账号，是一台真正能装进口袋的电脑：终端、SSH、自己的脚本和网页应用，界面也能改。但它不会让你躲过情报机构——基带仍是闭源固件，运营商仍知道你在哪；它只是少和谷歌及广告公司分享数据。它也跑不了银行等依赖安卓或谷歌完整性校验的应用，作者建议随身带 Linux 手机、家里留一台安卓机应付这些应用。把 Linux 装到具体机型要找对应 port、解锁 bootloader、安全刷机并修好暂时不能用的硬件，信息散落在 wiki、论坛和源码里，弄错就可能变砖。仓库把方法、安全规则和已有经验交给 AI 助手，也留给人读。README 较长（约 9400 字符）但结构清晰；这是 2026-11-21 新建、只有 8 star 的仓库，尚无社区验证，也没有 release。

## 它不是什么
1. 不是手机 ROM 或固件本身——README 明确说仓库不含固件，厂商固件是专有的、留在你自己的机器上。
2. 不是匿名或反追踪工具——它直说基带闭源、运营商仍定位，无法躲过情报机构。
3. 不是完整的安卓替代——银行与依赖谷歌校验的应用不能用。
4. 不是一键装机程序——需要按机型找 port、解锁、刷机、修硬件，仓促操作会变砖。
5. 不是通用教程站——主要围绕少数机型（如 Redmi Note 9 Pro Max）和两条具体发行版路线。

## 痛点
- 机型资料散落在 wiki、论坛和源码里，查起来费时且容易漏步骤。
- 刷机一旦弄错（刷错代号、低于防回滚索引、重新上锁）可能变砖或丢数据。
- 用 AI 助手做这类研究时，助手缺少针对具体机型的安全规则和历史经验。
- Linux 手机上很多服务只有桌面版网页应用，没有合适的手机界面。

## 核心功能（依据 README，注明来源）
- 提供 agent skill：把方法、安全规则和该读哪份指南写成可供 AI 助手加载的技能目录，并支持从克隆链接以便 git pull 更新（来源：README Contents / What's in this repository / Getting started）。
- 分步指南集：涵盖评估机型、小米从 Linux 解锁、安全刷机、Ubuntu Touch、postmarketOS 在非官方变体上的安装、高通调制解调器调试、无驱动充电、Chromium 信息亭、从电脑操作、社区与 AI 等（来源：README Guides）。
- 逐机型档案：每个手机一个文件夹，记录能跑什么、怎么装、哪些能用、需要哪些修补；目前列出 Redmi Note 9 Pro Max 与 Poco X8 Pro Max，后者还没有 Linux port（来源：README Phones）。
- 网页应用适配：把只在桌面屏幕上提供的网页服务改成适合手机的界面，已有 WhatsApp（单栏布局扩展）和 Lichess，并附开发工具（来源：README Apps）。
- 常用脚本与避坑清单：提供查机型信息、ROM 检查、打补丁、调制解调器诊断、截图、信息亭等工具，以及一行式的 gotchas（来源：README What's in this repository / scripts）。
- 明确的安全规则：绝不重新上锁已修改系统的 bootloader、绝不刷别的代号镜像、绝不低于防回滚索引、清空前先备份（来源：README Safety）。

## 使用场景
- 手里有旧安卓手机，想试试 postmarketOS 或 Ubuntu Touch，先评估这台机器能不能跑。
- 已经决定刷机，需要按安全清单逐步核对，避免变砖。
- 给 AI 编码助手装一个技能，让它替你查特定机型的资料并解释每一步。
- 在 Linux 手机上把常用网页服务（如聊天、棋类）改成可用的手机应用。
- 想给 Linux 手机挑一个可替换的桌面或界面（Phosh、Plasma Mobile、Sxmo 或全屏网页）。

## 适用人群
愿意折腾刷机、对 Linux 手机有兴趣的极客和开发者；使用 Claude Code 等支持 agent skills 的助手、想让助手帮忙做机型研究的人；关注去谷歌化、希望手机少上传数据的隐私爱好者。不适合只想即插即用、或严重依赖银行类安卓应用的人。
